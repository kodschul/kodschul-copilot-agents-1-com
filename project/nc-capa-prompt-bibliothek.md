# NC/CAPA-Prompt-Bibliothek Nordwind Medical

Gesammelte, an Fällen getestete Prompts. Ein Eintrag ist erst fertig, wenn er an mindestens einem Fall geprüft wurde. Bewährte Einträge werden mit dem Skill-Generator zu Skill-Dateien.

## Aufbau eines Eintrags

| Feld | Inhalt |
| --- | --- |
| Nr. / Titel | fortlaufend, Aufgabe in wenigen Worten |
| SOP-Bezug | Abschnitt der NC- oder CAPA-SOP |
| Prompt | wörtlich, kopierfertig |
| Benötigte Dateien | z. B. NC-SOP, Eingangsdatei |
| Getestet mit | Fall und Datum |
| Prüfhinweise | worauf beim Ergebnis zu achten ist |
| Wird zu Skill | Skill-Nummer oder „nein" |
