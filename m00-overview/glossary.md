# Glossar

| Begriff | Bedeutung | Modul/Lab |
| --- | --- | --- |
| Agent | Gespeicherte Kombination aus Anweisungen, Wissen und Skills für eine wiederkehrende Aufgabe | 2.1, 3.1 |
| Agent Builder | Bereich in Microsoft 365 Copilot Chat zum Anlegen und Konfigurieren eigener Agenten | 2.1 |
| Aufgabenplan | Liste der Aufgaben zur Umfangsbestimmung einer NC, je Aufgabe mit Datenquelle und Rolle | 3.2 |
| Bewertungsbogen | Raster K1–K7 zum Vergleich eines Agentenlaufs mit der realen Bearbeitung | 3.3, 4.1 |
| CAPA | Corrective and Preventive Action: Korrektur- und Vorbeugemaßnahme mit Ursachenanalyse und Wirksamkeitsprüfung | 3.2 |
| CAQ-System | System für Qualitätsdaten, Prüfaufträge und Prüfmittelbuchungen; der Agent hat keinen Zugriff | 3.2 |
| Containment | Eindämmung: Maßnahmen, die weitere Auswirkungen sofort begrenzen, getrennt von der Korrektur | 3.2 |
| Few-Shot | Prompt mit Anweisung und einem Beispiel einer guten Lösung | 1.3 |
| Halluzination | Plausibel klingende, aber erfundene Aussage eines Sprachmodells | 1.2 |
| Human in the Loop (HITL) | Mensch prüft jeden Entwurf, gibt Feedback und entscheidet über die Freigabe | 1.3 |
| Isolation | Sofortiges Sperren oder Sichern betroffener Objekte, z. B. einer Charge | 3.2 |
| Ishikawa | Ursache-Wirkungs-Diagramm nach den 6M (Mensch, Maschine, Methode, Material, Messung, Mitwelt) | 3.2 |
| Kontext | Rolle, SOP, Fall und Ausgabeformat, die einer Anfrage mitgegeben werden | 1.2 |
| KI-Wildwuchs | Uneinheitliche, nicht abgestimmte KI-Nutzung einzelner Personen ohne Standard und Verantwortung | 1.1 |
| LLM | Large Language Model: Sprachmodell, das das wahrscheinlichste nächste Token vorhersagt | 1.2 |
| NC | Nichtkonformität (Abweichung) von einer Anforderung | 1.3 |
| NC-Eigner | Rolle, die Problembeschreibung, Umfang, Containment und Korrektur verantwortet | 1.3 |
| Owner | Verantwortliche Person für Pflege und Tests eines Agenten | 5.1 |
| Parameter | Gewichte und Verbindungen im Modell, in denen Wissen gespeichert ist | 1.2 |
| Part 1, Part 2/3 | Eingang einer Meldung (Agenten-Eingabe) und reale Bearbeitung mit Risikobewertung (Referenz) | 3.3 |
| Prompt-Bibliothek | Sammlung getesteter Prompts mit SOP-Bezug und Prüfhinweisen | 1.3 |
| Prüfpunkte | Fünf Fragen zur Prüfung eines KI-Entwurfs: Quelle, nichts erfunden, getrennt, ursachenneutral, vollständig | 1.3 |
| Skill | Markdown-Datei mit einer wiederkehrenden Aufgabe: Wann verwenden, Eingaben, Vorgehen, Ausgabeformat, Grenzen, SOP-Bezug | 2.3 |
| SOP | Standard Operating Procedure: schriftlich festgelegter Prozess | 1.3 |
| Zero-Shot | Prompt nur mit Anweisung, ohne Beispiel | 1.3 |
